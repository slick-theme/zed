## [0.1.0] - 2026-11-06

### Added
- Eighteen variants: nine dark (Black, Red, Yellow, Magenta, Cyan, Blue, Orange, Green, Emerald)
  and nine light "Zesty" ones, for Zed, VS Code (including Cursor and VSCodium), Neovim and Ghostty.
- Neovim: highlights for about 25 popular plugins (gitsigns, telescope, nvim-tree, neo-tree, nvim-cmp,
  blink.cmp, which-key, noice, lazy, mason, trouble, mini.nvim and more).
- Neovim: a lualine theme for every variant.
- VS Code: an extension icon.
